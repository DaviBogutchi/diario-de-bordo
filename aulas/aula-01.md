# Aula 1 — Por que usar Git?

Aprendi que o Git guarda o histórico das mudanças de um projeto. Cada commit registra uma versão e tem uma mensagem explicando o que mudou. O GitHub guarda o repositório online, por isso fica mais fácil fazer um trabalho em grupo sem ter um monte de arquivos com nomes tipo final, final2 e final-agora-vai.

## Um exemplo

Imagina que eu estou fazendo um site e mudo a cor do botão da página inicial. Posso fazer um commit com a mensagem “Muda a cor do botão da página inicial”. Se depois eu mexer no menu e alguma coisa der errado, consigo olhar o histórico pra saber qual mudança veio antes e comparar as versões.

Uma coisa que eu entendi é que salvar o arquivo e fazer um commit são duas etapas. Quando salvo, guardo a mudança no arquivo. Quando faço um commit, registro essa mudança no histórico do projeto. Depois posso enviar os commits pro GitHub pra equipe acompanhar o que foi feito.
