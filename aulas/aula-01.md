# Aula 1 — Por que usar Git?

Aprendi que o Git guarda o histórico das mudanças de um projeto. Cada commit registra uma versão e tem uma mensagem explicando o que mudou. O GitHub guarda o repositório online, por isso fica mais fácil fazer um trabalho em grupo sem ter um monte de arquivos com nomes tipo final, final2 e final-agora-vai.
